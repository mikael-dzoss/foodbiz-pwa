# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's **Report a vulnerability** button
(Security tab, then "Report a vulnerability") on this repository. Do not open public issues,
pull requests or discussions for security problems.

## Supported versions

The project is pre-release. Only the `develop` branch is supported.

## What to expect

This is a solo-maintained project. You will get an acknowledgement within a week, and
updates as the report is investigated and fixed.
